# Portfólio profissional — Roberto

## Sobre o projeto

Este repositório contém meu portfólio profissional e acadêmico, desenvolvido como parte do projeto da disciplina **Design Profissional**.

O site apresenta minha formação em **Análise e Desenvolvimento de Sistemas**, interesses em Tecnologia da Informação e Robótica, competências em desenvolvimento, projetos acadêmicos e plano de evolução profissional.

## Objetivos

- Apresentar minha identidade profissional.
- Organizar projetos e atividades acadêmicas.
- Demonstrar minha evolução na área de TI.
- Utilizar o GitHub como espaço de documentação e portfólio.
- Preparar o projeto para publicação no GitHub Pages.

## Tecnologias utilizadas

## Publicação

No GitHub:

1. Criar ou abrir o repositório `portfolio-profissional`.
2. Confirmar que `index.html` está na raiz.
3. Abrir **Settings**.
4. Localizar **Pages**.
5. Em **Build and deployment**, escolher **Deploy from a branch**.
6. Selecionar a branch `main` e a pasta `/(root)`.
7. Salvar.
8. Aguardar a publicação.
9. Testar o endereço gerado em janela anônima e em outro dispositivo.
10. Inserir o endereço final neste README.
